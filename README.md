## 1. Project Overview

Regiotels Partnership Theme is a custom WordPress theme built for the partnership program page of [regiotels.com](https://www.regiotels.com/regiotels-partnership/) — a telecom infrastructure provider serving the hospitality sector. The theme powers the B2B-facing partnership landing page and lead generation funnel, targeting hotel operators and hospitality groups considering Regiotels connectivity solutions.

## 2. The Problem

Regiotels' partnership program required a dedicated digital presence that could independently present the partnership value proposition, capture qualified B2B leads (hotel operators), and communicate technical specifications in a format appropriate for both decision-makers and technical evaluators — without the visual noise of a generic corporate template.

---

## 3. The Solution & Architecture

A purpose-built WordPress theme designed as a high-conversion B2B landing experience, with a content architecture focused on the partnership value proposition and a lead capture system routing hospitality sector inquiries to the Regiotels commercial team.

### Architecture

- **ACF field groups** for all partnership content sections: value proposition, technical specifications, partner benefits, case studies, and the partnership inquiry form.
- **Partnership inquiry CPT** — Leads captured via the inquiry form are stored as WordPress posts with full submission metadata (hotel name, room count, location, current connectivity provider), enabling CRM-independent pipeline tracking.
- **Page templates** — The partnership page template separates layout logic from content, enabling the commercial team to update section content without touching template code.

---

## 4. Technologies Used

- **CMS & Backend:** WordPress 6.0+, PHP 8.0+, MySQL
- **Content Management:** ACF Pro — programmatic field groups for partnership content sections
- **Custom Post Types:** Partnership Inquiries (lead capture)
- **Styling:** Custom CSS — B2B technology sector design language
- **Live Site:** [regiotels.com/regiotels-partnership/](https://www.regiotels.com/regiotels-partnership/)

---

## 5. Design Process & UI/UX

The design language communicates technical competence and enterprise reliability — the trust signals required for B2B telecom purchasing decisions. Section structure follows a classic B2B conversion pattern: problem identification → solution presentation → social proof (partner case studies) → clear CTA. The inquiry form is positioned below the primary trust-building content, where visitors have built sufficient context to submit a qualified lead.

## 6. Project Outcomes

- **Qualified lead capture:** The structured inquiry form captures hotel-specific metadata (room count, location, current provider) that enables the commercial team to qualify and prioritise leads before first contact.
- **Content independence:** The Regiotels commercial team updates partnership benefits, case study content, and technical specifications independently.
- **B2B positioning:** The custom design communicates enterprise-grade credibility appropriate for hospitality sector procurement decisions.
